A single 95-character horror sentence — a smartwatch that counted 12,000 steps circling its owner's bed all night — written to `entry.txt` by a pure-stdlib Python program.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

This writes one line of horror to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), a single sentence of 95 characters, valid UTF-8, within the competition's 1–200 character gate. `main.py` validates the line before writing and verifies the file on disk after writing.
